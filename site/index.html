spoweb

Show what you're listening to on your website. A live Spotify now-playing card with Spotify's player, updated every 30 seconds, from one API key.

Install

npm install spoweb

React or Next.js

import { SpotifyNowPlaying } from 'spoweb';

export default function Page() {
  return <SpotifyNowPlaying apiKey={process.env.NEXT_PUBLIC_SPOWEB_KEY} />;
}

Plain JavaScript

import { createSpotifyClient } from 'spoweb';

const spotify = createSpotifyClient({ apiKey: 'YOUR_API_KEY' });
const { isPlaying, track } = await spotify.getNowPlaying();

Get an API key

Keys are issued by hand for now. Request one through apcodesphere.xyz.
