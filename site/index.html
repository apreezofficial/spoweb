Usage

Drop it in. Or call it yourself.

Use the React component, or the plain client if you want the data in your own UI.

React / Next.js
JavaScript
import { SpotifyNowPlaying } from 'spoweb';

export default function Page() {
  return <SpotifyNowPlaying apiKey={process.env.NEXT_PUBLIC_SPOWEB_KEY} />;
}

Plain JavaScript:

import { createSpotifyClient } from 'spoweb';

const spotify = createSpotifyClient({ apiKey: 'YOUR_API_KEY' });
const { isPlaying, track } = await spotify.getNowPlaying();
